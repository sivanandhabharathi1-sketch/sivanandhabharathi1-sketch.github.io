# Project thumbnail generation

Mode: built-in image-generation tool, edit mode. Each original project image was supplied as the edit target. Original images remain in project detail views. Outputs are encoded as WebP without resizing.

## Shared prompt (prepended to every project prompt)

Create a premium portfolio project thumbnail, landscape 16:10, a coherent series art direction for a charcoal #101113 and electric yellow #F2D80B website. Photoreal polished editorial art direction, sculptural composition, deep soft shadows, subtle technical grid and a single restrained yellow geometric arc or plane, quiet spacious framing, tactile materials, crisp subject. No added titles, no captions, no watermark, no decorative fake UI, keep all important content within central 75% so responsive crops remain safe. Input image is the edit target and source artwork; preserve the project's authentic subject and screen/interface/logo content faithfully. Change the presentation, setting and framing to fit the series.
